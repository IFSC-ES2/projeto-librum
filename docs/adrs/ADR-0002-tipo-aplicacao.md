# ADR-0002 - Tipo de aplicação

## Contexto

Precisávamos definir se o Librum seria um app mobile, desktop ou web nesta primeira versão.

## Decisão

Aplicação **web responsiva**, acessível pelo navegador.

## Alternativas consideradas

- App mobile nativo com React Native
- PWA (Progressive Web App)

## O que isso implica

Mais fácil de publicar e acessar sem precisar instalar nada. A experiência no celular não vai ser tão fluida quanto um app nativo, mas é suficiente para o MVP.
