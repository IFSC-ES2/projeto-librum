# ADR-0001 - Linguagem e framework principal

## Contexto

A equipe precisava escolher as tecnologias principais do projeto levando em conta o que já conhece, o tempo disponível e o suporte da comunidade.

## Decisão

Usar **React.js** no frontend e **Java** no backend.

## Alternativas consideradas

- Next.js e Vue.js como alternativas de frontend
- Python como alternativa de backend

## O que isso implica

O React.js é uma biblioteca amplamente usada para criar interfaces web, com muitos recursos e uma comunidade enorme. O Java no backend é uma escolha sólida para APIs, com bastante suporte da comunidade e familiaridade da equipe. A separação de linguagens entre front e back exige atenção na hora de definir como os dois lados vão se comunicar, mas é uma estrutura bem estabelecida no mercado.
