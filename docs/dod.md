# Definition of Done


- [ ] A funcionalidade foi implementada e funciona conforme descrito na issue
- [ ] Os critérios de aceitação da issue foram verificados manualmente
- [ ] O código está no repositório, em uma branch separada
- [ ] Foi aberto um **Pull Request** para a branch principal
- [ ] O PR foi aprovado por pelo menos **um integrante da equipe**
- [ ] Nenhum erro grave foi introduzido - o projeto ainda builda sem problemas
- [ ] A documentação foi atualizada se a mudança afetou algum fluxo ou decisão de arquitetura
- [ ] A issue foi movida para **"Done"** no board do projeto
